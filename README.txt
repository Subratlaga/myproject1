SUBRAT LAGA PORTFOLIO
======================

This is a plain HTML/CSS/JavaScript portfolio website.

HOW TO RUN:
1. Extract the ZIP file.
2. Open the "subrat-portfolio" folder.
3. Double-click index.html.
4. The website will open in your browser.

No Node.js, XAMPP or server is required.

FILES:
- index.html       Main website
- css/style.css    Design and responsive layout
- js/script.js     Menu and dark-mode functionality
- images/          Place your profile images here
- resume/          Place your PDF resume here

You can edit the text directly in index.html.
